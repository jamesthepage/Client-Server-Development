# Writing Maintainable, Readable, and Adaptable Programs

When writing code, I try to keep things organized so it is easier to understand and make changes later. In the Grazioso Salvare project, I used a CRUD Python module to connect the database to the dashboard. This helped keep the database operations separate from the dashboard code instead of having everything mixed together. It also made it easier to reuse the code and fix problems when they came up. I could use this same CRUD module in future projects that need to connect to a database, even if the project is for something completely different.

# Approaching Problems as a Computer Scientist

For the Grazioso Salvare project, I had to look at what the client needed and figure out how to use the database and dashboard to meet those needs. I had to think about more than just getting the code to work. I also needed to make sure the dashboard displayed the right information and allowed users to find the records they needed. This project was different from some of my other assignments because I had to get different parts working together instead of just focusing on one problem at a time. In the future, I would start by figuring out what the client wants, planning how the database should be set up, and testing the different parts as I go. I think doing this would help me catch mistakes earlier and make the project easier to manage.

# The Importance of Computer Science

Computer scientists use programming and technology to solve problems and make things easier for people. The dashboard I created for Grazioso Salvare could help employees find dogs that meet certain requirements for rescue work without having to look through records manually. This could save time and help them make better use of the information they have. Working on this project helped me understand how databases and programming can be used together to solve a real problem. It also showed me that writing code is only part of the job. You also have to understand what the user needs and make sure the finished product is useful.
